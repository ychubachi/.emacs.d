* はじめに
+ Emacsの設定ファイルです（Emacs 30で動作確認）
+ パッケージ管理は [[https://github.com/progfolio/elpaca][elpaca]] + use-package
+ [[FILE:early-init.el][early-init.el]] で起動初期の設定（GC、フレーム）を行い、設定本体は [[FILE:init.el][init.el]] 1ファイルにまとめている
+ init.el 内は [[https://github.com/jdtsmith/outli][outli-mode]] 対応の見出し（;;; / ;;;;）でセクション分けしている。見出しの折り畳みや imenu-list サイドバーでの一覧表示に対応

* ファイル構成
| ファイル      | 内容                                                         |
|---------------+--------------------------------------------------------------|
| early-init.el | GCしきい値、package.elの無効化、メニュー・ツールバー、最大化 |
| init.el       | 全設定（outli-modeの見出しで以下のセクションに分割）         |

* lisp/*.el を init.el に統合 (2026-10-04)
モジュールごとに分割していた lisp/init-*.el を、見通しの良さを優先して init.el 1ファイルに統合し、outli-modeの見出し階層で区切る形に変換した。対応関係は「ファイル構成」の節のとおり（ファイル名→セクション見出し）。あわせて組み込み機能の設定（旧init-core.el/init-files.el相当）も「Emacs本体の基本設定」セクションに一本化した。

* ファイル構成の再整理 (2026-09-30)
設定の内容・種類に応じて lisp/*.el を再配置した。以下の履歴に出てくるファイル名は当時のもので、現在の場所は次のとおり。
+ magit / diff-hl / vc-handled-backends → init-vcs.el
+ AUCTeX / pandoc-mode / ox-latex / ox-html / ox-publish / ox-pandoc / org-preview-html / eww → init-document.el
+ undo-tree（init-core.elから）、ace-window / swap-buffers / perspective → init-editing.el
+ フォント（init-japanese.elから）、ウィンドウ余白（org-modernから）、hydra-zoom → init-ui.el
+ no-littering / org(最新版) → init-package.el
+ shell-pop → init-misc.el
+ メール送信設定(smtpmail) は削除。未使用の init-emacs.el も削除
+ auto-revert / dired-dwim-target の重複設定を init-files.el に一本化
